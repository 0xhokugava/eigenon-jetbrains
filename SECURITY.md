# Security Policy

## Supported versions

Eigenon Quantum Toolkit for JetBrains is in early development and has no published releases yet. Security fixes are made on the `master` branch.

| Version | Supported |
| --- | --- |
| Unreleased (`master`) | Yes |
| Older commits | No |

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue, discussion, or pull request.

Use [GitHub private vulnerability reporting](https://github.com/0xhokugava/eigenon-jetbrains/security/advisories/new) to send the maintainers:

- a description of the vulnerability and its potential impact;
- affected versions or commits;
- steps or a minimal proof of concept that reproduces the issue;
- any suggested mitigation, if known.

We aim to acknowledge reports within seven days. We will coordinate remediation and disclosure with the reporter and publish an advisory after a fix is available when appropriate.

Please avoid accessing data that is not yours, disrupting services, or publicly disclosing an unresolved vulnerability.
